# 7 天记忆计划（每天 10 分钟）

## Day 1：三铁律（只记 3 条）
不看资料，写出：
1. 具体 > 聪明
2. 说要做什么，不说不做什么
3. 分解 > 一次性
→ 写不出 → 重读速查表 §1 → 再写 → 对照 → 重复直到写对。

## Day 2：参数（只记 2 对）
- temperature ↔ top_p（二选一）
- frequency penalty ↔ presence penalty（二选一）
→ 闭眼默写；默写错就只重读这一行，不要重读整篇。

## Day 3：技术选型（只记 4 个最常用）
Zero-shot / CoT / RAG / ReAct
→ 对每个写一句"何时用"，不要背定义。

## Day 4：Agent 三组件
规划 + 工具 + 记忆
→ 用你手头一个真实任务，指出它缺哪一环。

## Day 5：上下文工程五原则
消除歧义 / 期望显式化 / 可观测性 / 迭代 / 平衡
→ 任选一个你写过的 prompt，用这 5 条检查，找出 1 个改进点。

## Day 6：反模式（只记 3 条）
模糊指令 / 盲目 CoT / 示例偏斜
→ 找出你过去写过的 prompt 中的 1 个反模式。

## Day 7：综合自测（闭卷）
1. 三铁律？
2. 参数二选一？
3. 技术选型 4 个？
4. Agent 三组件？
5. 一个反模式？
→ 全对 = 掌握最小核心；错的 = 明天只补那一块。

## 原则
- 每天只记当天的，不往前补。
- 错的只重读那一行，不重读整篇。
- 每天必须产出：一句话总结"今天记住了什么"。
