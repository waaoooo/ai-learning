## 🚧 关键约束（实测，必须知道）

| 约束 | 影响 | 应对 |
|---|---|---|
| **推理模型默认烧光 max_tokens** | 正文为空 | 一律传 `extra_body={"thinking": {"type": "disabled"}}` |
| **免费模型限流频繁** | `429 访问量过大` | 所有调用带**指数退避重试**；Agent 循环里更必需（调用次数翻倍） |
| **HuggingFace 被墙** | 下不了模型 | 用本地方案或可访问源 |
| **神经 embedding 不可用** | 语义检索降级为词面匹配 | char n-gram TF-IDF 模拟，**接口保持可替换** |
| **eval 需要困难集** | 简单集 100% 是假象 | 必须构造同义改写问题暴露短板 |

## 🧠 核心概念速查

| 概念 | 一句话 | 出处 |
|---|---|---|
| **RAG** | 先查资料再回答，治"不知道却自信地编" | W2 |
| **切片** | 切碎了事实，检索再准也白搭；重叠保边界 | W2 |
| **embedding** | 文本 → 向量 → 余弦相似度；词面 ≠ 语义 | W2 |
| **评测** | 用数字说话；简单集会骗人，困难集才真实 | W2 |
| **置信度门控** | 检索分数低就别硬答，把静默错误变显式拒答 | W2 |
| **tool_choice** | `auto` 让模型自己决定用不用工具 | W3 |
| **执行循环** | 模型决定 → 代码执行 → 结果回喂 → 再决策 | W3 |
| **错误处理** | 工具侧明确标注 + 模型侧写死约束（两道防线） | W3 |
| **安全阀** | `max_steps` 防无限循环 | W3 |
| **代码编排 / LLM 决策** | 确定性交给代码，不确定性交给 LLM | W3 |

## ✅ 学习约定

1. **交互式**：一次只给一个概念 + 一个可运行示例 + 一个验收动作，然后停下等确认。
2. **可验证**：每个任务都有验收标准，不靠"看起来对"。
3. **可复现**：所有代码、配置、测试都能重跑，不给纯概念。
4. **不擅自假设**：信息不足先追问。
5. **诚实**：跑不通就说跑不通，不编造结果。
