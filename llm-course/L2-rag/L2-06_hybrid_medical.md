## 1. 为什么需要混合检索

- **向量检索**：语义理解强，能匹配"高血压"↔"血压升高"，但对精确术语/缩写/编号弱
- **关键词检索（BM25）**：精确匹配术语、编号、专有名词，但无语义
- **混合**：两者互补，显著提升召回率与准确率

医疗场景尤其需要：疾病名、药品名、ICD 编码等精确术语 + 症状描述的语义。

---

## 2. BM25 原理

BM25 是经典关键词检索排序函数：

```
score(q, d) = Σ_{t in q} IDF(t) * (tf(t,d)*(k1+1)) / (tf(t,d) + k1*(1 - b + b*|d|/avgdl))
```

- `tf`：词在文档中的频率
- `IDF`：逆文档频率，罕见词权重高
- `k1`（~1.5）、`b`（~0.75）：调参
- 中文需分词；本课用字符级 n-gram 近似（生产用 jieba/HanLP）

---

## 3. 融合策略

- **加权分数融合**：`score = α·norm(vec) + (1-α)·norm(bm25)`，需归一化
- **RRF（Reciprocal Rank Fusion）**：`score = Σ 1/(k + rank_i)`，无需归一化，鲁棒，推荐默认
- **两阶段**：BM25 粗召回 + 向量 rerank（或反之）

## 5. 小结

- 混合检索 = 语义 + 关键词，互补；医疗/法律/代码场景收益明显。
- RRF 融合简单鲁棒，推荐默认；加权融合需归一化。
- 中文分词质量影响 BM25；生产用专业分词器。
